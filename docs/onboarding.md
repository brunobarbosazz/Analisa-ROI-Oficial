# Onboarding

## Prerequisites

- Node.js 20 or newer.
- npm.

## Start locally

```text
npm install
npm run dev
```

Open the local URL printed by the server. Use the landing page action to enter the demo workspace. Data changes are local to the browser.

## Troubleshooting

Run `npm run typecheck`, `npm run build` and `npm test`. If the port is occupied, stop the existing local server or use the port option documented in `server.js`.
